# Kelime Oyunları

Kelime Oyunları, Türkçe kelime oyunlarını bir arada sunan web ve mobil platformdur. Kullanıcılar giriş yapmadan misafir olarak veya hesap oluşturarak oyun oynayabilir.

## Proje Dokümantasyonu

Projenin teknik detayları, mimarisi ve kuralları aşağıdaki ana belgelerde tanımlanmıştır:
- [Teknik Referans Belgesi (PRD)](prd.md)
- [Geliştirme Görevleri (TASKS)](TASKS.md)

## Başlangıç

Projeyi yerelde çalıştırmak için:

```bash
npm install
npm run dev
```

Tarayıcınızda [http://localhost:3000](http://localhost:3000) adresine giderek projeyi görüntüleyebilirsiniz.
